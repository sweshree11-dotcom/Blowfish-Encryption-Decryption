Learn About Blowfish

What is Cryptography?

Cryptography is the technique of protecting information by converting readable data (plaintext) into an unreadable form (ciphertext). Only someone with the correct key should be able to recover the original message.

What is Blowfish?

Blowfish is a symmetric-key block cipher designed by Bruce Schneier. It processes data in 64-bit (8-byte) blocks and supports variable-length keys from 32 to 448 bits.

Symmetric-Key Encryption

Symmetric encryption uses one shared secret key for both operations. The sender encrypts with the key, and the receiver uses the same key to decrypt.

How Encryption Works

The application creates a fresh random 8-byte initialization vector (IV), adds a validation marker to the message, and encrypts it using Blowfish in CBC mode with PKCS5 padding. The IV is placed before the ciphertext, and the combined bytes are displayed as Base64.

How Decryption Works

The Base64 text is decoded. The first 8 bytes are extracted as the IV and the remaining bytes as ciphertext. Blowfish CBC decrypts the data with the same key, removes the padding, and checks the validation marker before showing the original message.

Advantages and Limitations

Blowfish is fast, freely available, and supports variable-length keys. However, its 64-bit block size is small by modern standards. It is a legacy algorithm and is not recommended for protecting new sensitive applications.

Educational note: This page demonstrates the Blowfish algorithm using CBC mode. CBC encryption by itself does not authenticate ciphertext; the validation marker is only a basic wrong-key / corruption check, not a modern message-authentication mechanism. Do not use this demonstration to protect real sensitive information.
